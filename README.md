# Soran Match Time

ئەپێکی وێبی مۆبایل-فرێندلی بۆ کاتی یارییەکانی تۆپی پێ بە کاتی عێراق (Asia/Baghdad / UTC+3).

## تایبەتمەندییەکان
- ئەمڕۆ، سبەی و ٧ ڕۆژی داهاتوو
- پاڵەوانێتییە سەرەکییەکان و فلتەری هەڵبژاردن
- ئەنجامی یارییە تەواوبووەکان و دۆخی یارییە زیندووەکان
- نوێکردنەوەی ئۆتۆماتیکی هەر ٢ خولەک
- API لە `api/matches.js` و داتای ESPN

## بڵاوکردنەوە لە Vercel
1. ZIP ـەکە بکەرەوە.
2. فۆڵدەری `Soran_Match_Time` بار بکە بۆ GitHub وەک repository ـێکی نوێ.
3. لە Vercel، `Add New → Project` هەڵبژێرە و repository ـەکە import بکە.
4. Build settings بە default بهێڵەوە و Deploy بکە.
5. دواتر URL ـی `*.vercel.app` بکەرەوە لە مۆبایل.

تێبینی: لیستی پاڵەوانێتییەکان بریتییە لە هەندێک خولی سەرەکی، نەک هەموو خول و وڵاتێکی جیهان. بەردەستبوونی داتا بە سەرچاوەی ESPN پەیوەستە.
